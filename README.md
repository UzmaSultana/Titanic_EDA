# Titanic_EDA

This repository includes an in-depth analysis of the Titanic dataset, accompanied by
1. Dataset
2. Summary of findings
3. Report of findings

A PDF report that presents key findings and observations from the data. 

The analysis includes a summary of findings, highlighting significant trends and relationships, such as the correlation between gender, passenger class, and survival rates. 
Various visualization methods (e.g., bar charts, histograms, and scatter plots) are used to effectively identify and communicate these insights. Each visual is accompanied by an explanation of the patterns observed, helping to clarify the relationships between different features like age, fare, and class, and how they influenced survival outcomes.

This comprehensive approach allows users to easily interpret the data and gain a deeper understanding of the factors that contributed to the Titanic disaster.
